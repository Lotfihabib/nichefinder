# NicheFinder

Personal, read-only market research tool for my own future Etsy shop.

## What it does
- Searches public active listings by keyword via the Etsy Open API v3
- Reads public shop and listing review data to assess demand, competition and price ranges
- Produces private reports for my own product decisions

## What it does not do
- No OAuth, no access to any shop's private data, no buyer data
- No listing creation or edits
- No scraping of etsy.com
- No resale or redistribution of Etsy data; caching follows the Etsy API Terms of Use
- Single user (me), rate-limited well within Etsy's limits
